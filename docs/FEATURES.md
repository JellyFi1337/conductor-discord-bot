## 1. Что это за бот

Conductor — Discord-бот для одного сообщества. Основной и тестовый экземпляры — два разных приложения: каждый живёт только на серверах из своего списка в `.env`. Он ведёт человека от входа до своего места на сервере, даёт следящим одно досье и квоты, а специальному следящему — контроль над следящими.

| Круг | Кто | Что даёт бот |
| --- | --- | --- |
| Участник | новичок и все без ранга | верификация, роли, поиск команды, комнаты, тикеты, `/profile`, `/help` |
| Следящий | watcher, senior, chief | досье, санкции, тикеты, квоты, канал действий |
| Специальный | special и владелец сервера | `/admin`, отмена дел, заявки, дайджест, данные |

Язык интерфейса — русский. Команды — слэш (`/…`), только на сервере. Ответы — карточки Discord Components V2 с кнопками и модалками. Одно исключение: новые видео YouTube — обычное сообщение, не карточка.

## 2. Общие принципы

### 2.1 Два бота и забор серверов

Основной и тестовый Conductor — два приложения Discord с разными токенами. `BOT_MODE` выбирает, какой процесс поднять из этого `.env` (`live` или `test`/`beta`). Чтобы запустить обоих сразу, нужен второй контейнер со своим env. С любого сервера не из списка этот бот выходит сам. Оба приложения изначально приватные.

### 2.2 Ранги и ключи

Бот не использует галку Discord «Администратор» как универсальный ключ команд. Она открывает команды **только пока ранг Специального никому не привязан** (свежий сервер). После привязки — только обход лимитов автомода и квот. Если роль Специального исчезнет, запасной вход откроется снова.

| Ранг | Роль | Уровень | Роль в команде |
| --- | --- | --- | --- |
| special | Специальный следящий | 4 | Права, кадры, репутация, достижения, данные |
| chief | Главный следящий | 3 | Ведение сервера: верификация, роли, автомод, статистика, голос, тикеты, лестница |
| senior | Старший следящий | 2 | Просмотр настроек, `/admin panel`, розыгрыши, опросы, тикеты |
| watcher | Следящий | 1 | Замечания, муты, тайм-ауты, сборы, опросы |
| — | нет ранга | 0 | Обычный участник |

Ранг человека — максимум по его ролям. Нельзя наказать, снять или назначить равного или старшего.

**Ключи** — именованные разрешения (`mod.ban`, `tickets.claim`, …). Умолчания — в каталоге ниже и в `/admin` → Права. К ключу можно добавить обычные роли без ранга через YAML-импорт.

**Administrator** открывает команды бота, пока ранг Специального никому не привязан. После привязки обходит только лимиты автомода и дневные квоты. Каждый обход пишется в лог. Владелец приложения Discord и id из `OWNER_USER_IDS` обходят проверки рангов и ключей.

### 2.3 Три слоя проверки

1. Ключ действия.
2. Ранг (иерархия).
3. Владелец ресурса (комната, тикет, розыгрыш, опрос, сбор, группа) или ключ `*.manage`.

Бан, кик, отмена розыгрыша, удаление опроса, отмена сбора, закрытие тикета, забывание данных, команды владельца — всегда в два шага. Подтвердить может только тот, кто вызвал.

Отказ называет нужный ранг или лимит цифрой. Ошибка — карточка с кодом `E-xxxx`, без трассировки в канал.

### 2.4 Роли только через брокер

Все выдачи и снятия идут через брокер. У каждой управляемой роли один владелец: персонал, Old, лестница, репутация, достижения, верификация, мут, роли по выбору. Подсистемы не трогают чужие роли. Если привязанную роль удалили с сервера, брокер пропускает её id и ставит остальные; в лог администрации — одна карточка на гильдию, пока роль не привяжут заново.

### 2.5 Состояние в базе

Панели, тикеты, комнаты, розыгрыши, напоминания — в базе. После рестарта бот сверяет мир с базой. Удалённые вручную панели помечаются устаревшими и не воскрешаются молча.

## 3. Что видит участник

### Первые десять минут

| Шаг | Что видит человек | Что делает бот |
| --- | --- | --- |
| 1. Вошёл | Только «правила» и «верификация» (перекрытия на роль верификации ставит владелец сервера) | Записывает инвайт; всплеск входов — сигнал главному следящему |
| 2. Нажал «Я человек» | Карточка первых шагов: роли → поиск команды → тикеты → `/profile` → `/help` | Выдаёт роль верификации |
| 2′. Написал в «верификации» | ЛС с причиной и контактом для апелляции | Бан делом от бота; пинг главного в канал действий |
| 3. Открыл #роли | Две карточки: **подписки** и **игры**. У игры подпись «открывает: #канал · 🔊 войс» | Выдача и снятие одним запросом к брокеру |
| 4. Хочет поиграть | В #поиск-команды кнопка «Ищу команду» → игра, сколько нужно, комментарий → пост с пингом роли и кнопкой «Иду» | Набор живёт 2 часа; при сборе — комната из хаба; пинг роли не чаще раза в 15 минут на игру |
| 5. Что-то не так | Панель тикетов или `/bug` / кнопка «Сообщить об ошибке» на карточке сбоя | Аноним — переписка в ЛС; баг-репорт — в `#баг-репорты` без трассировки |
| 6. Хочет понять себя | `/profile`: репутация (старт 50, уровень «Надёжный»), лестница, достижения, роли, стаж | Данные из леджера и репутации |

### Дальше — недели

Лестница даёт «постояльца» на 50 сообщениях. Достижения — за принятые баги, идеи и жалобы. Опросы и новые видео приходят с пингом роли подписки. Напоминания — `/remind`. Комнаты голоса — с правами владельца на канал. Розыгрыши и сборы — кнопками на карточке.

### Что бот делает против воли — и как это ограничено

- **Автомод.** Первые сутки (`newcomer.hours`, умолчание 24) лимиты умножаются на `newcomer.factor` (0.5): 5 эмодзи вместо 10. Каждое срабатывание — ЛС, дело от бота, списание как за обычный тайм-аут.
- **Санкции следящих.** ЛС №1 сразу, ЛС №2 с развёрнутой причиной, кнопка «Обжаловать» в ЛС для замечаний, тайм-аутов и мутов. Бан обжалуется только по внешнему контакту — ЛС забаненному Discord не доставляет.
- **Репутация.** Падение до 0 — автобан. Помилование возвращает к старту 50.

`/help` → «Памятка участника» повторяет личные команды и кнопки без служебных ключей.

## 4. Что может следящий

Одна точка входа: правый клик на участнике → **«Досье»** (то же из `/profile`). Карточка только вызвавшему: репутация и уровень, ступень, стаж, активные санкции с окончанием, последние дела, заметки, автомод за 7 дней, открытые тикеты, наблюдение.

Кнопки по ключам вызвавшего: Замечание · Тайм-аут · Мут · Снять мут · Заметка · Наблюдение · Кик (chief+) · Бан (chief+) · Отменить дело (chief+). Каждая кнопка идёт через тот же сервис, что и слэш `/mod`: квоты, иерархия, ЛС, канал доказательств.

| Инструмент | Ограничитель |
| --- | --- |
| Замечание, тайм-аут, мут | Квота в сутки, иерархия, краткая причина, канал доказательств (напоминание через 24 ч), обжалование из ЛС |
| Кик, бан | Только chief+, подтверждение, квота, ЛС до санкции, пинг главного в канал действий |
| Чистка, замок канала | Ключ, запись в канал действий |
| Наблюдение | Срок ≤ 30 дней; новые срабатывания и дела пишутся в канал действий |
| Заметка | Видна только следящим, входит в досье |
| Тикеты | Видимость по типу; исход обязателен; лог тикетов с правкой причины |

Квоты по умолчанию (настраиваются в `/admin` → Квоты):

| Ранг | Тайм-ауты и муты / сутки | Баны и кики / сутки |
| --- | --- | --- |
| Следящий | 10 | 0 |
| Старший | 20 | 1 |
| Главный | 40 | 3 |
| Специальный | без лимита | без лимита |

Мут и тайм-аут — один счётчик. Кик считается в баны. Отказ по квоте виден в канале действий. Administrator обходит квоту — строка в лог.

Слэш `/mod` остаётся для тех, кто печатает быстрее, чем кликает.

## 5. Что может специальный следящий

| Задача | Инструмент |
| --- | --- |
| Видеть действия следящих | Канал `#действия`: одна строка на действие; пинг главного на бан, кик и санкцию вне бота |
| Не дать наказывать бесконтрольно | Квоты; отказ виден в канале действий |
| Проверить, за что наказали | Канал доказательств и транскрипт в деле; просроченные без причины — напоминание, через 72 ч — главному |
| Отменить решение | `/mod pardon` или «Отменить дело» в досье: снимает тайм-аут/мут, возвращает репутацию, пишет участнику и следящему |
| Жалоба на наказание | Тикет-обжалование из ЛС; наказавший в него не входит; «Оставить в силе» / «Отменить наказание»; дальше — владелец сервера |
| Заявки | Цепочка следящий → главный → владелец сервера. Баг и предложение видит только special |
| Оценить работу | `/watchers list`: квоты сегодня, дел за 7 дней, отменённых за 30, просроченных доказательств, закрытых тикетов и средняя оценка. С человеком — карточка и лента. «Приостановить на N дней» — ключи отказывают, роль ранга остаётся |
| Еженедельная картина | Дайджест в канал действий: топ по делам, отмены, просрочки, квоты, тикеты без ответа, воронка новичков, автомод |
| Правила автомода | Карточка в `#автомод`: «Перечитать файл» и заявка владельцу бота. Файл сам бот не правит |
| Данные | `/admin` → Данные: перепись и история (`stats.ingest`, chief+); экспорт (`data.manage`) и забывание (`data.forget`) — special |
| Настройка сервера | `/admin panel` — все привязки каналов, рангов, порогов и панелей |

Иерархия: chief управляет watcher и senior; special — всеми; владелец сервера — последняя инстанция обжалований; владелец бота — файл `data/automod.yml` и `/owner`. Кто закрыл или наказал, своё обжалование не рассматривает.

## 6. Справочник по модулям

### 6.1 Верификация

Кнопка «Я человек» выдаёт роль через брокер и отвечает карточкой первых шагов. Любое сообщение в канале — бан с фиксированной причиной, ЛС и делом от бота. Следящий пропускается. Administrator — обход с записью в лог раз в сутки. Всплеск входов (порог на странице Сигналы) пишет в канал действий с пингом главного. Карточку выкладывает `/admin` → Верификация. Текст правил в `#правила` пишет владелец сервера — бот канал не заполняет.

### 6.2 Роли по выбору

Два меню в `#роли`: подписки (новые видео, опросы, анонсы, поиск игры) и игры. Селект — полный желаемый набор этого меню: выбранные выдаются, невыбранные из меню снимаются, остальные роли не трогаются. Игровые роли бот сам в каналы игр не пускает — перекрытия ставит владелец сервера; карточка показывает «открывает», если у роли уже есть `view_channel`. Теги подписок: `youtube`, `polls`, `announce`, `lfg`. Игры добавляет `/admin` → Роли по выбору.

### 6.3 Поиск команды

Постоянная карточка «▸ Ищу команду». Автор выбирает свою игровую роль и число людей: от 0 до 100, **0 — без ограничения**. Быть в голосе не обязательно. Один открытый набор на человека. Набор живёт 120 минут (настраивается). Пинг роли игры — не чаще раза в 15 минут на игру. Автор свой набор кнопкой «Иду» не занимает. Список «идущих» открывается постранично и держит 1000+ человек. Когда мест хватит, бот открывает комнату из хаба и перечисляет участников.

### 6.4 Голосовые комнаты

Заход в хаб «➕ создать комнату» создаёт временную **голосовую** комнату без парного текстового чата, переносит человека и ставит панель в чат голосового канала. Владелец получает перекрытия на канал: видеть, входить, говорить, стримить, управлять каналом, перемещать, мутить, заглушать, приоритет. Одна комната на человека. Пустая удаляется через 40 секунд. Панель: имя, лимит, замок, скрыть, впустить, отказать, передать, выгнать, закрыть вход, заявки, приглашение, забрать, битрейт, статус, слияние. «Выгнать» только отключает от голоса — зайти снова можно, пока не нажато «Закрыть вход». Право Discord «Администратор» проходит сквозь запрет входа; бот всё равно отключает такого человека. Названия и карточки без порядковых номеров. Голосовая комната — не больше 99 мест (`user_limit = 0` значит без лимита). `/voice` перевыкладывает панель.

### 6.5 Тикеты

Панель в `#тикеты`. Темы по умолчанию: Жалоба, Вопрос, Баг сервера, Предложение, Анонимно, заявки (следящий / турнир / съёмочная). При открытии бот тегает автора отдельным сообщением (анонимный тикет — без имени и без упоминания). Обжалование наказания — скрытая тема из ЛС: на карточке нет общей кнопки закрытия, только «Оставить в силе» и «Отменить наказание»; наказавший решение не принимает. Баг и предложение видит только special. Аноним — ретрансляция ЛС, в канале имени нет; если ЛС закрыты, тикет не откроется. Персонал закрывает через исход. Автор при самозакрытии получает «решено». Автозакрытие — «без действия». Исход и причина видны в `#лог-тикетов`; кнопка «Транскрипт» отдаёт полный файл переписки. Кнопки на карточке: взять, снять, заметки, вызвать старшего, закрыть, переименовать, приоритет, передать, добавить, убрать. После закрытия — оценка 1–5 и обжалование (заявка или жалоба с исходом «отклонено» / «бессмысленно», 7 дней).

### 6.6 Модерация и доказательства

Каждая санкция — дело со сквозным номером, краткой причиной (не короче 8 символов) и длительностью. Бот пишет ЛС №1 сразу и открывает канал в категории доказательств. Кнопка «Отправить причину» шлёт ЛС №2 и закрывает канал транскриптом. Просроченные без причины — напоминание следящему, через 72 ч — главному. Бан и кик — подтверждение. Если Discord не принял бан или кик, дело сразу отменяется и уходит корректирующее ЛС. Softban нет. Замок и снятие — одна команда `/mod lock` (срок `0` или «снять»). Чистка — не старше 14 суток, лог-каналы бота не трогает.

### 6.7 Автомодерация

Источник правды — файл `data/automod.yml`, не `/admin`. Бот читает его при старте и по кнопке «Перечитать файл». Опечатка — прежние правила остаются, в лог уходит «файл правил не принят». Нет файла — встроенные умолчания, `/diagnose` ставит ⚠. Счётчики — в памяти, окно по умолчанию 60 минут. Срабатывание — тайм-аут на срок правила (умолчание 10 мин), дело от бота, списание как за обычный тайм-аут, развёрнутая причина в аудите Discord, ЛС и карточке лога. Правила: эмодзи, приглашения (чужие ссылки; свои инвайты сервера не трогает), `@everyone` / `@here`, повторы, упоминания людей и ролей, гифки. Исключения — special, администратор Discord, владелец сервера. Заявка на изменение — кнопка в `#автомод`, решение принимает владелец бота; файл сам не меняется.

### 6.8 Репутация, лестница, достижения

Старт **50**, пол 0, потолок 100. Шесть уровней с ролями:

| Уровень | Счёт | Имя по умолчанию |
| --- | --- | --- |
| 0 | 0–9 | Изгой |
| 1 | 10–29 | Подозрительный |
| 2 | 30–49 | Обычный |
| 3 | 50–69 | Надёжный |
| 4 | 70–89 | Уважаемый |
| 5 | 90–100 | Образцовый |

Уровень 0 замораживает рост и лестницу. Счёт 0 — автобан. Кик репутацию не уменьшает (`kick_hit=0`). Замечание −5, мут −10, тайм-аут −2 за каждые 10 минут (не меньше −2 и не больше −20). Рост +1 за 50 сообщений или 30 минут голоса, не чаще раза в час. Помилование возвращает к 50.

На живом сервере со старыми счетами (старт 100) сначала `/owner wipe reputation` — автоматического пересчёта нет.

Лестница, одна роль, без понижения:

| Ступень | Условие по умолчанию |
| --- | --- |
| Гость | старт |
| Постоялец | 50 сообщений (голос и реакции выключены: порог 0) |
| Житель | 500 сообщений **и** 50 часов голоса **и** 30 дней стажа |
| Друг сервера | 365 дней **и** 1000 сообщений **и** 100 часов голоса |

Достижения из исходов тикетов плюс ручная правка в `/admin` → Достижения: Фиксер 1–3, Идеолог 1–3, Бдительный 1–4. Грант даёт +5 репутации.

`/profile` — три вкладки: репутация, активность, достижения. Чужую карточку открывает следящий.

### 6.9 Следящие

`/watchers appoint` выдаёт одну ранговую роль и снимает низшие. Special через бота по умолчанию не назначается. `/watchers duty` отмечает смену — прав не добавляет, даёт видимость. Служебная заметка о следящем — не дело модерации. Приостановка — все ключи отказывают с объяснением до срока.

### 6.10 Опросы, YouTube, статистика

`/poll start` публикует карточку в `#опросы` и пингует роль подписки. Виды: открытый, анонимный, скрытый до конца. Закрыть и удалить — кнопки. Деанонимизация — `/poll deanonymize`, только закрытого, в канал опроса и в лог.

YouTube — опрос RSS без ключа API, раз в 10 минут. Сообщение в `#видео` с пингом роли «Новые видео». Фид добавляет `/admin` → YouTube.

`#статистика` — одна карточка без кнопок: следящие и смена, люди/боты/бусты, выбранные роли, топ каналов за 7 дней, голос. Обновление раз в 10 минут, только если цифры изменились. Состав на сводке `/stats` берётся из того же снимка пульса, что вкладка «Сейчас». «Сегодня» и пики часов подписаны как UTC.

### 6.11 Розыгрыши, сборы, группы, напоминания

`/giveaway` — модалка приз / срок / победители, кнопка «Участвую». `/event` — Иду / Может / Не могу, лист ожидания, пинг идущих и постраничный список на 1000+, временный войс, чек-ин; `0` мест — без ограничения. `/group` — закрытый канал; видят участники, бот, chief и special. Создать может любой с репутацией строго выше порога (по умолчанию 50; новичок со стартовыми 50 — нет), либо держатель `group.create`, special, администратор Discord или владелец сервера. Квоты для остальных: 1 новая за скользящие 24 часа и 3 открытые сразу (архивные не считаются). Участников из команды приглашают в ЛС кнопками «Вступить» / «Отказаться»; закрытое ЛС оставляет приглашение в `/groups`. Неделя тишины переносит канал в архив (категория «Архив групп», виден только персоналу); история хранится для жалоб, полное удаление — по сроку или вручную. `/remind` — себе в этот канал; без параметров — список и отмена. `/bug` — форма «что делали / что произошло / код E-XXXX»; отчёт в `#баг-репорты`, не больше трёх в час; персонал разбирает кнопками «Принято», «Исправлено», «Не баг» (ключ `bug.triage`). Та же форма открывается кнопкой «Сообщить об ошибке» на карточке сбоя — код в кнопке совпадает с записью `CriticalLog`.

### 6.12 Рекрутинг

`/recruit link` выдаёт человеку бессрочный инвайт без лимита. Одна активная ссылка на человека. Повтор возвращает ту же. Отозвать — той же командой. `/recruit report` — пришло / активно / сейчас на сервере, без имён новичков. Удалённый в Discord инвайт помечается в карточке конкретной ссылки (команда с человеком или кодом). Канал задаёт `/admin` → Рекрутинг.

### 6.13 Логи, статистика, пульс, Old

Три лог-канала: участники, администрация, действия следящих. Телеметрия — дневные счётчики, сброс раз в 30 с. `/stats` — вкладки Сейчас / Сводка / Участники / Каналы / Связи; с человеком — историческое досье. Вкладка «Сейчас» для дежурных добавляет служебный блок (ключ `pulse.staff`). Сигналы «сообщество стихло» — `/admin` → Сигналы, в лог администрации, без пинга. Критический сбой команды, панели или слушателя — карточка в `#лог-администрации` с тем же кодом `E-…`, что видит человек: команда и аргументы, канал, кто нажал, ранг Conductor, права Discord, нехватка прав бота, файл и строка. На карточке человеку — кнопка «Сообщить об ошибке» с этим кодом. Версия сборки (`0.9.0`) видна в шапке `/diagnose`, в отчёте `/bug` и в логе `startup_ready`. Ожидаемые отказы (нет прав, кулдаун) в этот журнал не пишутся.

Old: Ruby (первые 3 месяца жизни сервера) → Emerald (2 года) → Sapphire (1 год) → Amethyst (остальные, кто зашёл до сегодня). Не бот, не меньше 10 сообщений, зашёл не сегодня. Выдача только через `/loyalty` по плану. Ручные выдачи откатываются.

### 6.14 Настройка и каркас

`/admin panel` — единственная панель настроек. Первый экран: список страниц со статусом и селекты (по 12 опций, лимит Discord — 25 в одном). Страницы: Общие, Логи, Ранги, Права, Кадры, Модерация, Квоты, Old, Репутация, Лестница, Достижения, Розыгрыши, Голос, Тикеты, Автомод, Верификация, Роли по выбору, Статистика, Опросы, YouTube, Поиск команды, Рекрутинг, Сигналы, Каркас, Витрины, Данные.

`/admin` → Каркас — мастер структуры: каталог, сопоставление существующих каналов и ролей, кнопка «Собрать сервер» (создаёт недостающее и пишет привязки), пересборка прав, отправка витрин. Свои каналы сопоставляйте до сборки: имена чужих бот не меняет. Сборка автоматически ждёт короткие ограничения Discord и продолжает, с общим бюджетом около трёх минут. Собственных квот на число созданий нет. Если ожидание слишком долгое, отчёт показывает причину и недоделанное (`HELD`/`PARTIAL`); повтор продолжает настройку без дублей. Удалённый канал каркаса обнуляет привязки, гасит панели и кладёт карточку в `#структура` с кнопкой восстановления.

`/owner seed` — то же со слэша владельца бота. По умолчанию создаёт недостающее; `mode` «только подтянуть» не создаёт, а привязывает найденное. Повтор чинит по id и не переименовывает. `with_old` — роли Old. Special выдаётся владельцу сервера, если ранг ещё никому не выдан. Свои чаты — в категории «Сервер». `/diagnose` → Настройка: интенты, права, позиция роли, логи. Готовность — «сервер готов к работе». Каркас проверяет ту же таблицу построчно (включая перекрытия Verified и рангов); кнопка «Починить» создаёт недостающее или чинит права.

`/admin` → Данные: перепись и чтение истории по `stats.ingest` (chief, special); экспорт JSON по `data.manage` и забывание по `data.forget` (special). Страница видна тому, у кого есть любой из этих ключей; контролы без ключа скрыты. Отдельных слэш-команд экспорта нет.

## 8. Каркас сервера

Единственная таблица, с которой сверяются три вещи: **`/admin` → Каркас** и **`/owner seed`** создают недостающее и подтягивают существующее, **`/diagnose`** проверяет ровно это построчно.

Имена оформлены: одно эмодзи и разделитель «・», корневое слово прежнее (`📜・правила`). Прежние простые имена остались алиасами, поэтому сервер, собранный старой версией, узнаётся и не пересоздаётся. Бот хранит **id**: переименование уже привязанного канала ничего не ломает.

Категория «Общение» и её каналы — необязательная часть: бот их создаёт и выставляет им права наравне с остальными, но `/diagnose` не считает сервер несобранным, если их нет. Свои чаты сверх этого владелец сервера создаёт сам; внутри категорий каркаса они наследуют права. Discord закрывает сервер после пачки create/delete — не удаляйте объекты пачками; повтор сборки безопасен и не плодит дубли.

## 10. Границы

Чего в боте **нет**:

- тихого часа;
- дней рождения;
- публичного приветствия в канал;
- цитат и контекстного меню «Цитировать»;
- статуса AFK;
- челленджа недели;
- доски лучших сообщений;
- кампании поддержки (`/support`, окно, бейдж, кнопка «Поддержать»);
- кампаний роста (`/growth`);
- команд `/setup`, `/config`, `/data`, `/rep`, `/activity`, `/pulse`, `/showcase`, `/docks`, `/ticket`, `/mod note`, `/mod softban`, `/mod unlock`.

Ограничения, которые есть в коде:

- ЛС забаненному не доставляется — обжалование бана только по внешнему контакту из карточки бана.
- Право Discord «Администратор» проходит сквозь запрет входа в комнату; бот отключает такого человека.
- Голосовая комната — не больше 99 мест.
- Архив групп виден только персоналу.
- Счётчики автомода живут в памяти: рестарт обнуляет окно часа, срабатывания в базе остаются.
- YouTube — только RSS, без ключа API и без эмбеда.
- Не отправляет данные на каталоги серверов, не бампит чужие площадки. Команд `/like`, `/bump`, `/up`, `/info` нет.
- Не показывает онлайн без интента Presence (интент выключен).
- Не выдаёт право «Администратор». Не назначает special через бота по умолчанию. Не банит special другого special.
- Не понижает ступень лестницы. Не выдаёт Old по одному человеку — только план `/loyalty`.
- Не создаёт чужие чаты и не пишет текст в `#правила`.
- Не работает на серверах вне забора. Интерфейс только на русском.
- Каталожных ботов сам не кикает — показывает их в `/diagnose`.

## 11. Технические требования

| Что | Требование |
| --- | --- |
| Хостинг | Docker: бот + PostgreSQL 16 (Windows 11 через Docker Desktop или Ubuntu 24.04, пакет `deploy/ubuntu-24.04`). Локально без Docker — SQLite |
| Стек | Python 3.12+, discord.py 2.7, SQLAlchemy 2, Alembic, structlog, PyYAML, aiohttp |
| Интенты | Server Members, Message Content, Direct Messages (`dm_messages`, включается кодом). Presence не обязателен |
| Права бота | Manage Roles, Manage Channels, Ban Members, Kick Members, Moderate Members, Move Members, Manage Messages, View Audit Log, Create Instant Invite. Роль бота выше ролей каркаса |
| Переменные | матрица в `README.md`; обязательны `BOT_MODE`, токен выбранного режима, его список серверов, а для Docker ещё `POSTGRES_PASSWORD` |
| Каталог данных | `automod.yml`, `.command-hash`, `.heartbeat`; в Docker это `./data` с хоста в `/app/data`. С чистого листа: `python scripts/wipe_data.py --yes` |
| Миграции | Без `AUTO_MIGRATE` бот не стартует на схеме старше head: нужен `conductor db upgrade` или `AUTO_MIGRATE=true` |
| Живость | Планировщик раз в 30 с трогает `.heartbeat`; healthcheck контейнера считает файл старше 120 с отказом |
| Разработчик | Владелец приложения Discord (или team admin/developer) и id из `OWNER_USER_IDS` |
| Правила автомода | `data/automod.yml`, эталон — `data/automod.yml.example` |
| Нагрузка | ~600 участников, профиль edge: буфер телеметрии 30 с, очередь логов 2000 (рабочий на канал), 24 одновременных REST, 12 нажатий / 10 с на человека, склейка ролей 3 с. Стаж автомода и отстранения кэшируются; история держит окна каналов, не все id сообщений |

Первичная настройка: права боту → `/diagnose` → Настройка → `/admin` → Каркас → Собрать сервер (свои каналы — сначала Сопоставить) → Витрины → правила в `#правила` → `/diagnose` → Готовность. Пошагово — [SETUP.md](SETUP.md). Приёмка — [ACCEPTANCE.md](ACCEPTANCE.md). Windows — [DEPLOY.md](DEPLOY.md), пустой Ubuntu — [ubuntu-24.04](../deploy/ubuntu-24.04/README.md).
